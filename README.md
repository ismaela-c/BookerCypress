**Testes de API – CRUD com Cypress - Restful Booker API**
**Sobre o Projeto**
Este projeto consiste na automação de testes de API utilizando o Cypress, 
validando as operações de CRUD (Create, Read, Update e Delete) da entidade Booking, 
com uso de autenticação via token.

A API utilizada é a Restful Booker, uma API pública voltada para prática de testes de serviços REST.
